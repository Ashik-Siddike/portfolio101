## 🚀 Key Highlights & Architectural Features

- 🎥 **Programmatic Video Engine (Remotion)**: 60 FPS motion graphics rendered natively in React for real-world projects (*IntervueAI*, *Affiliate Automation*, *247School*, *Brand Identity Suite*).
- 🪐 **Interactive WebGL Three.js Canvas**: Dynamic particle constellation field and 3D floating refractive cyber artifacts.
- 🧲 **Magnetic Spring Cursor**: Organic velocity-based fluid trailing cursor with spring physics and contextual hover states.
- 🤖 **Interactive AI & Tech Sandbox**: Live Google Gemini resume parsing simulator, tokenized UI component customizer, and full-stack architecture node diagrams.
- 📱 **2.5D Holographic Interactive Card**: Real walking entrance video, mouse-parallax tilt physics, scanlines, and HUD telemetry.
- 📄 **Interactive Resume Modal & Verified Credentials**: In-app full CV viewer and direct contact gateways (WhatsApp, Email copy with confetti, GitHub, LinkedIn).

## 💻 Local Development Setup

```bash
# Clone the repository
git clone https://github.com/Ashik-Siddike/portfolio101.git

# Navigate into directory
cd portfolio101

# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Build for production
npm run build
```
